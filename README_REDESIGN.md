# Eskaya Website Redesign

This source folder contains the implemented visual redesign.

## What changed
- Reworked page layouts into responsive image-and-text sections.
- Added relevant local image assets to the existing `src/assets/images/` collection.
- Updated Home, Community, History, Language, Creators, navigation, and shared page styling.
- Removed the old global `#root` width and margin rules that could interfere with the page layout.
- Kept the existing informational content and page purposes while improving hierarchy, spacing, and image placement.
- Added responsive layouts for desktop, tablet, and mobile.

The project still expects its existing Vite/React project files outside this `src/` folder. Replace the project's `src/` folder with this one.
